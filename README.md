# Shravya Fulbandhe — Java Developer Portfolio

A polished, responsive portfolio website built from the supplied resume, aimed at entry-level Java Developer roles.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code with Live Server.
3. The resume download is included as `Shravya-Fulbandhe-Resume.docx`.

## Publish on GitHub Pages
1. Create a GitHub repository (e.g. `shravyaf-portfolio`).
2. Upload the files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Use the URL provided by GitHub Pages on your resume and LinkedIn.

## Before sending to HR
- Add real GitHub links for your projects after publishing the source code.
- Test the website on mobile and desktop.
- Keep all claims aligned with what you have actually built and can explain in an interview.
- This portfolio does not invent project metrics or claim unlisted professional experience.
- No specific job description was provided; content is currently tailored to common entry-level Java Developer requirements.
